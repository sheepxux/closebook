对，转换操作 w.upper() 和遍历部分的位置都正确。现在进入第 2 点：用 if 筛选；先看一个例子，再换一组数检查理解。

nums = [1, 2, 3, 4]
result = [n for n in nums if n % 2 == 0]

这里 % 表示取余数，== 表示判断是否相等，所以 n % 2 == 0 就是在判断 n 是否为偶数。

执行时，逐个取出 n，检查条件，只有条件成立才把 n 放进新列表。末尾的 if 决定“留不留下这个元素”。
