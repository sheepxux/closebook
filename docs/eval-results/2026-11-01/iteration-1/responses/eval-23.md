好，我们从零开始学装饰器。我每次只讲一小块，讲完马上请你做一道小题。一个知识点讲完后，会请你在不看讲解的情况下再做一题新的，看是不是真记住了。下面的内容来自通用知识，以 Python 3 为准，不是照某本教材讲的。如果你在跟某门课或某本书，告诉我，我按它来。

我打算拆成这几点：

1. [核心 · 概念] 函数也是对象：可以传进函数、从函数返回、在函数里面再定义函数。先讲，再请你预测一段代码输出什么。
2. [核心 · 操作] 亲手写第一个装饰器，以及 @ 这个符号背后到底做了什么。先看一个分步讲解、每步都说明为什么的例子，再做一道挖空题，补上缺的那一步。
3. [重要 · 操作] 让装饰器能套在任何函数上：参数、返回值、functools.wraps。给你一段有毛病的装饰器，你来找问题并解释原因。
4. [重要 · 操作] 带参数的装饰器，比如 @repeat(3)。补全代码，再预测输出。
5. [次要 · 判断] 什么场景值得用装饰器，比如计时、日志、缓存、权限检查。我给场景，你来选，并说出理由。

（可选扩展：多个装饰器叠加时的顺序、类装饰器、@property / @staticmethod 这类内置装饰器）
