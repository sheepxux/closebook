这里不对：(1, 0) 其实是 B 的特征向量，特征值是 3。"对角矩阵"只是一眼就能看出来的特例，并不是有特征向量的前提条件。这个误会值得早点抓出来，不然后面遇到非对角矩阵就会直接跳过。

换个角度讲：判断一个向量是不是特征向量，唯一的办法就是真的去算 B·v，再看结果是不是 v 的某个倍数。

矩阵乘向量的算法是：结果的每一行，等于矩阵那一行和向量逐项相乘再相加。
B = [[3, 1], [0, 2]]，v = (1, 0)：
  第一行：3×1 + 1×0 = 3
  第二行：0×1 + 2×0 = 0
所以 B·v = (3, 0) = 3·(1, 0)。方向没变，只放大了 3 倍，所以 (1, 0) 是特征向量，λ = 3。右上角那个 1 正好乘上了 0，没起作用。

记住一句话：要看的不是矩阵长什么样，而是 A·v 算出来是不是等于 λ·v。
