好，你学过一点，那我们就先考再讲：每个点先问你一道摸底题，根据你的回答补漏，然后合上笔记再测一次。这份笔记是技术类内容，所以我会多让你先预测结果、自己写命令，再对答案。

我把笔记拆成这几个点：

1. [核心 · 概念] 镜像 vs 容器：先预测"删掉容器后会怎样"，再追问为什么
2. [核心 · 操作] 常用命令（build / run / ps / logs / exec）：我给场景，你直接写出命令
3. [重要 · 判断] 命名卷 vs 绑定挂载：我给场景，你选一个并说理由
4. [重要 · 概念] 层缓存：看一段 Dockerfile，预测改了某一行之后哪些步骤会重跑
5. [次要 · 事实] 常见默认端口：快问快答卡片

30 分钟我建议重点做 1 到 4，最后请你用自己的话把整体讲一遍。第 5 点时间够就快速过一遍，不够就放进下次复习。想调整（删掉、合并、换顺序）直接说。

没问题的话，直接回答第 1 点的摸底题。先别翻笔记，答"不知道"也完全可以，这题不算分：

你用某个镜像执行 docker run 起了一个容器，进去在 /app 下新建了一个文件 note.txt。接着用 docker rm 删掉这个容器，再用同一个镜像 docker run 一个新容器。新容器的 /app 里还有 note.txt 吗？为什么？

回复格式：有/没有，因为……，信心 1-3（1 = 猜的，2 = 比较确定，3 = 非常确定）
