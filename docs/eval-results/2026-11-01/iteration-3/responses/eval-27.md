第 2 点：用 if 筛选，只留下想要的元素

先看循环写法：

 nums = [1, 2, 3, 4, 5, 6]
 result = []
 for n in nums:
 if n % 2 == 0:
 result.append(n)
 # 结果：result 是 [2, 4, 6]

n % 2 的意思是"n 除以 2 的余数"。余数是 0，n 就是偶数。所以这段代码只把偶数放进新列表。

写成推导式就是：

 [n for n in nums if n % 2 == 0]

从左往右对照着读：
1. 最前面的 n 是要放进新列表的东西。
2. for n in nums：从 nums 里一个一个取出 n。
3. if n % 2 == 0：只有满足这个条件的 n 才放进去，不满足的直接跳过。

注意 if 写在最后面，后面不加冒号。

规则就一句话：[要放的东西 for 变量 in 列表 if 条件]，条件成立才放进去。
