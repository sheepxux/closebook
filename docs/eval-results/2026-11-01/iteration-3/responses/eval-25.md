这里不对：(1, 0) 是 B 的特征向量，特征值是 3。判断它不看矩阵是不是对角的，要直接算出 B·v，看结果是不是 v 的倍数。上一块我只给了结果，没讲怎么算，这里补上。

矩阵乘向量：矩阵的每一行和向量对应位置相乘，再相加，得到结果的一个分量。
B = [[3, 1], [0, 2]]，v = (1, 0)：
第一行 (3, 1)：3×1 + 1×0 = 3
第二行 (0, 2)：0×1 + 2×0 = 0
所以 B·(1, 0) = (3, 0) = 3·(1, 0)。方向没变，长度放大 3 倍，所以特征值是 3。

再对比 (0, 1)：
第一行：3×0 + 1×1 = 1
第二行：0×0 + 2×1 = 2
B·(0, 1) = (1, 2)，不是 (0, 1) 的倍数，方向变了，所以 (0, 1) 不是 B 的特征向量。

一句话：不是对角矩阵也可以有特征向量。要判断一个向量是不是特征向量，就算出 A·v，再和 v 比一比。
