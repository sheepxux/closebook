以下按通用 Rust 知识讲；你可以随时调整范围，或提供教材让我跟着讲。我们用短代码追踪“这份文字归谁”，帮助理解所有权。

先看两行，不需要安装 Rust：

    let a = String::from("茶");
    let b = a;

第一行：String::from("茶") 创建一份文字，let a 给它一个变量名。此时 a 是这份文字的“所有者”。

第二行：这份文字的所有权从 a 交给 b，这叫“转移”（move）。之后不能再通过 a 使用这份文字。

对于这里的 String，赋值会转交所有权，不会自动复制出另一份文字。

现在把上面的解释移出视线，只看这道检查题：

    let first = String::from("苹果");
    let second = first;
    let third = second;

填空：创建文字 → 第一次转交 → 第二次转交 → 最后由 ___ 拥有。
