这里的误解是把“对角矩阵”当成了必要条件。上一题中：
B·(1,0) = (3×1+1×0, 0×1+2×0) = (3,0) = 3·(1,0)
所以 (1,0) 是 B 的特征向量，特征值是 3。

我们换个例子算一遍，练习根据向量的变化来判断：
C = [[2,1],[0,3]]
C·(1,1) = (2+1, 0+3) = (3,3) = 3·(1,1)

判断依据是：原向量非零，乘完矩阵后，结果是否等于原向量乘同一个数。矩阵不必是对角矩阵。
