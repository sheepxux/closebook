我先按通用 Rust 知识讲；你可以随时调整范围，有教材也可以改按教材。

假设 Rust 中有一份文字数据，由变量 a 持有。变量可以先理解成程序里给数据起的名字，a 是这份数据的“所有者”。

把这份数据的所有权交给 b 后，b 成为所有者，a 就不能再使用那份数据。这种交接叫“移动”（move），交接并没有复制出第二份数据。

这里的核心规则是：同一份值，在同一时刻只有一个所有者。

现在先别回看解释，试一道小检查：

一份文字数据的所有权经历了：
x → 移交给 y → 移交给 z

此时，最初的 x 还能使用这份数据吗？用一句话说明理由，并附上信心 1–3（1＝猜的，2＝比较确定，3＝很确定）。
