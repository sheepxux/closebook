# MCP 改进的行为评测证据

中文结果说明见[验证报告](../../../mcp-hardening-validation.md)。本目录保留原始失败与后续修复结果，不合并成单轮全绿记录。

| 目录 | 内容 |
|---|---|
| `initial/` | 34 例首轮回答；33 例评分为 145/151，用例 14 的评分超时 |
| `grading-timeout-retry/` | 同一份用例 14 回答的补评分，4/4；没有重新生成回答 |
| `followup/` | 修复后重跑 7、8、11、12、22，原始评分 22/26 |
| `override-recheck/` | 进一步明确用户坚持题型的处理后重跑 11、12，9/9 |
| `teaching-recheck/` | 补齐真实代码示例和课程范围后重跑 23、24、26，14/14 |
| `supplemental/` | 自动检查记录、MCP 源码摘要、用例 4 独立复核、22 的实际 JSON 验证、33 的工作区核对、MCP 参数 schema 验证，以及后续桌面真实回传和排序 DOM 定向核查 |

各轮的 `responses/` 保存面向学习者的最终助手回复，`observations/` 保存整个可见回复和实际工具调用，`grading/` 保存每项期望的判定及引用。`source-hashes.json` 是受测 skill 快照的 SHA-256；`evals-snapshot.json` 是这次使用的 34 个用例定义。`manifest.json` 可用于检查这些公开证据文件的内容。

运行器复制的 skill 不含评测定义，执行者看不到期望；独立评分者看到场景、附件、全部可见回复和工具结果。模型为 `gpt-6-astra`，推理设置为 `ultra`。工具选择题使用实际可调用的记录型替身，未显示真实桌面卡片。评分不是答案正确性或平台支持的保证。

后续桌面验收单独记录在 `supplemental/desktop-acceptance-live.json`：七种形式共 9 条由 MCP App 送达同一聊天的真实消息，不计入上述模型行为评分。排序前两次不符、用户的误点说明与第三次成功补检均保留；回忆卡的翻面时序另有用户明确确认。`automatic-checks.json` 保留自动检查结束当时的状态；它里面“等待桌面验收”的记录早于这批真实回传。

为避免公开本机信息，移除了原始 CLI 事件、工具调用的宿主元数据与配置；私人绝对路径以占位符替换。除此之外，没有改写助手回复、调用参数或评分结论。原始完整日志留在本地审计目录。

`interrupted-run.json` 记录最后三例的一次中断，未完成结果没有计入统计。用例 4 的原评分与复核结论并存；用例 22 的原评分缺少验证器运行证据，其真实机器验证另列在 `supplemental/`，没有反向覆盖原评分。
