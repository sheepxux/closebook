**知识点 1：特征向量是什么**

先补一个工具，矩阵乘向量的算法：

```
| a  b |   | x |   | a·x + b·y |
| c  d | · | y | = | c·x + d·y |
```

例子，取矩阵

```
A = | 2  1 |
    | 1  2 |
```

- 向量 v = (1, 1)：Av = (2·1 + 1·1, 1·1 + 2·1) = (3, 3) = 3 · (1, 1)。方向没变，只是变成原来的 3 倍长。
- 向量 u = (1, 0)：Au = (2·1 + 1·0, 1·1 + 2·0) = (2, 1)。(2, 1) 不是 (1, 0) 的倍数，方向被掰歪了。

原理一句话：矩阵乘一个向量，一般会把它转到别的方向；但有些特殊向量乘完以后还在原来那条直线上，只被拉长、缩短或反向，这种向量叫**特征向量**，被拉伸的倍数叫**特征值**，写成 Av = λv。所以 v = (1, 1) 是 A 的特征向量，对应的特征值是 3；u = (1, 0) 不是。

这一点是概念，但结果能当场算出来对不对，所以我用"先预测、再验证"：先凭理解下判断，再动手算，猜错的地方最能暴露理解上的偏差。

**你的题（乘法规则可以看，但别回头翻 v 和 u 那两个例子怎么下的结论，不然就变成照着抄了）：** 还是这个 A，换成向量 w = (1, −1)。

1. 先不算，预测：w 是不是 A 的特征向量？如果是，特征值是多少？附上把握度 1–3（1 = 瞎猜，3 = 很确定）。
2. 再用上面的乘法规则算出 Aw，写出结果，看看你的预测对不对。
