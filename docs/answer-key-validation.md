最初六个自然请求涵盖 Python 循环与列表推导式、Git 分支与合并、自由落体、一次函数、细胞结构和英语时态。第一轮有五组使用了练习页模板，生物组另做了独立页面。修改技能描述和出题规则后，又重跑了 Python、Git、生物三组。接手时，九个 Codex 进程均已结束，原始产物全部找回且未改动。

## 浏览器验证

Chromium 在八份模板练习页上测试了 **73 道自动判分题、469 次输入**，其中正确或等价输入 347 次，错答或无效单位输入 122 次。原始数据通过 **458/469** 次检查。11 次失败分别是九个合法 Git 等价写法，以及上述英语缩写的两种撇号写法。测试中的错误输入均被拒绝，页面没有异常。16 道自评书面题未计入自动判分统计。

定稿模板直接读取未迁移的旧 JSON 时，通过 **449/469** 次输入：两处 Git 条数参数写法已修复，但 11 次容器空格变体需要显式声明下文的比较模式；另有九次失败仍来自命令或语言答案缺项。这个兼容性变化有明确原因：若仅凭括号就将答案当作容器，也会错误接受普通字符串输出中的空格变化。

独立的修正版题库补齐已验证的答案，并为真实容器预测设置 `comparison: "container"`，通过 **469/469** 次输入。这是数据迁移和修复回归，不能计作模型生成能力的提升。哈希核对确认八份原始题库均已保留。

## 永久改进

- 普通 `build_lesson.py` 构建和 `--check` 都会执行受支持的 Python 追踪题；`--run-code` 仅保留为兼容参数。执行过程与答案不符时，构建失败。
- 核对器在每一步冻结可变对象的值，检查新增和变化的变量、执行顺序、输出及容器类型，拒绝遗漏状态变化或控制流步骤。仅允许省略最后一次不改变状态的循环检查，以及规则已说明的函数返回衔接步骤。
- 自动执行限定在一个小型教学代码子集中，语法树、内置函数和方法均采用允许列表；使用独立解释器、临时目录、时间与资源限制。导入模块、文件或网络访问、反射及其他不支持的语法会被拒绝。这不是通用 Python 沙箱。
- 执行轨迹核对**不会**推断自然语言预测问题的答案；这些答案仍须独立核对。非 Python 追踪题仍须人工审查。
- 代码答案默认精确匹配并区分大小写。显式设置 `comparison: "container"` 的问题可忽略容器标点附近的空格，但保留内部字符串的内容，防止将 `(hello, world)` 一类普通文本误当成元组。旧追踪题若漏列空格变体，只有在问题确实要求容器值时才应补这个字段。
- 终端匹配保留选项与值的对应关系，只调整已知独立 Git 开关的顺序；常见 `git log` 条数写法保留其数值参数。35 次浏览器回归输入覆盖了这些边界，包括选项放到子命令前、引号不闭合、选项冲突、字符串内容被改动，以及真实 shell 不会视为分隔符的 Unicode 空白。
- `references/html-lesson.md` 已加入独立答案核对、与舍入要求相容的容差、可达的滑块目标、真实 Git 状态检查，以及常见语言和命令替代答案的要求。

初次验证时，仓库完整测试套件 **121/121 项通过**，其中包含真实 Chromium 测试。后续人工复核引出的修复，其验证结果在下节单独记录。

## 用户人工复核后的修复

用户完成六道待审题的复核，并提供 **31 次真实浏览器作答**，没有修改自动勾选。五道排序题通过，附带两条措辞建议；完形题暴露了一处排版兼容问题：使用 U+2018 左弯撇号的 `‘ve known`、`‘s not seen` 被拒绝。

修复只针对 `language_production` 的问答和填空，将 U+2018、U+2019、U+0060、U+02BC 统一为 U+0027。它不会删除撇号、放过语法错误、改写保存的作答原文，或改变代码和终端的比较规则。Python 题面已明确列表只初始化一次、最后只打印一次；英语排序题已明确要求不倒装的普通肯定陈述句。原始生成数据与用户提交的复核证据均保留。

**验证结果：**116/116 项非浏览器测试通过，其中新增五项在 Node 中执行模板里的实际 JavaScript 判分函数和提交回调。用这些回调回放用户记录的 31 次输入，31 次均符合预期：只有左弯撇号那组从“不对”变为“正确”。13 个页面通过严格构建校验并重建，技能校验和打包检查通过。本次是代码层回放，不是新一轮浏览器实测。浏览器工具此前拒绝本地 `file://` 访问并禁止绕过，因此没有重新运行浏览器测试；较早的浏览器结果只作为旧模板版本的历史证据。

复核报告中的两点解释也需修正。普通肯定句的 `since` 时间短语不会自行触发主语与助动词倒装，因此 `Since 2021, have I lived here` 不作为普通肯定陈述的等价答案。排序总分依据最佳最长公共子序列（LCS）比例：完全一致判正确，不完全一致但比例至少 50% 判部分正确，更低则判不对；逐位勾叉只显示位置差异。因此，漏收的合理顺序仍可能被完全判错，出题时仍须补全 `alternatives`。
