# 研讨课材料：远程办公会损害创新吗？

**观点 A：会损害。** 偶然交流（走廊对话、午饭闲聊）是跨团队想法碰撞的重要来源。一项针对大型科技公司的研究发现，全员远程后跨部门协作网络变得更"静态"、更孤立。新人也更难通过观察学习隐性知识。

**观点 B：不一定。** 创新更依赖深度专注和多元人才。远程让公司可以招到更分散、更多元的人；异步书面沟通让决策过程留痕、更容易被别人复用。部分研究显示远程团队在专利数量上没有显著下降。

**观点 C：取决于工作类型。** 探索性、早期的创意工作受益于面对面；执行和打磨阶段远程效率更高。混合办公的关键是"为什么来办公室"，而不是"来几天"。

**课堂要求：** 能概括三种观点的核心论据，能说明各自证据的局限（样本、测量指标），并能为自己的立场给出理由和最强的反驳。
