# 药理学术语表（第 1 章，需全部背下）

| 术语 | 英文 | 定义 |
|---|---|---|
| 半衰期 | half-life (t½) | 血药浓度下降一半所需的时间 |
| 生物利用度 | bioavailability (F) | 药物进入体循环的比例和速度 |
| 首过效应 | first-pass effect | 口服药物经肝脏代谢后进入体循环的量减少 |
| 治疗指数 | therapeutic index (TI) | LD50 / ED50，越大越安全 |
| 激动剂 | agonist | 与受体结合并产生效应的药物 |
| 拮抗剂 | antagonist | 与受体结合但不产生效应，阻断激动剂 |
| 部分激动剂 | partial agonist | 与受体结合，只产生部分最大效应 |
| 效能 | efficacy (Emax) | 药物能产生的最大效应 |
| 效价强度 | potency (EC50) | 产生 50% 最大效应所需的浓度，越小越强 |
| 表观分布容积 | volume of distribution (Vd) | 体内药量 / 血药浓度 |
| 清除率 | clearance (CL) | 单位时间内清除药物的血浆体积 |
| 负荷剂量 | loading dose | 迅速达到目标浓度的首剂 = Vd × 目标浓度 |
| 维持剂量 | maintenance dose | 维持稳态的剂量 = CL × 目标浓度 × 给药间隔 |
| 稳态 | steady state | 约 4–5 个半衰期后给药量与消除量相等 |
| 零级动力学 | zero-order kinetics | 单位时间消除固定药量 |
| 一级动力学 | first-order kinetics | 单位时间消除固定比例的药量 |
| 耐受性 | tolerance | 反复用药后效应减弱 |
| 快速耐受 | tachyphylaxis | 短时间内反复用药效应迅速减弱 |
| 药物相互作用 | drug interaction | 一种药物改变另一种药物的效应或浓度 |
| 前药 | prodrug | 本身无活性，体内代谢后才有活性 |
